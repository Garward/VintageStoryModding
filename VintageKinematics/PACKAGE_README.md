# Vintage Kinematics

Vintage Kinematics adds kinetic power, automated machines, item and liquid logistics, moving contraptions, powered tools, and the Kinetic Warehouse to Vintage Story.

This mod is required on both the client and server. It does not require any other mods.

## Getting Started

Open the Survival Handbook and select the Vintage Kinematics category. Start with **Kinetics for Dummies** and **Progression Overview**. The handbook explains power generation, stress, gearing, machine input and output, filters, contraptions, piping, and warehouse storage.

Early kinetic power comes from hand cranks, treadwheels, and counterweight drives. Later progression includes coal motors, flywheel banks, vanilla mechanical-power bridges, geothermal bores, and geothermal steam engines.

## Main Features

- A separate kinetic network with RPM, stress capacity, stress demand, gearing, clutches, and reversers.
- Powered belts, funnels, filters, pipes, pumps, and machine automation.
- Sieves, crushers, sawmills, extractors, forge presses, mixers, bores, and other production machines.
- Moving gantry contraptions with drills, saws, carried storage, and selectable structures.
- The Kinetic Warehouse, providing searchable shared storage with expandable capacity and belt input and output.
- Powered equipment including drills, saws, kinetic boots, backpacks, and the Mechanical Binder.

## Installation

Place the Vintage Kinematics zip in the Vintage Story `Mods` directory in your data folder. Multiplayer servers and connecting players must use compatible versions of the mod.

Keep the mod as a zip. It does not need to be extracted.

## Help and Diagnostics

Most kinetic blocks show their RPM, stress use, network capacity, and current state while you look at them. Check those details first when a machine is not running.

For detailed rules and troubleshooting, use the in game Vintage Kinematics handbook pages. When reporting a problem, include the Vintage Kinematics version, Vintage Story version, relevant client or server logs, and a description or screenshot of the setup in either the forum or discord thread.
