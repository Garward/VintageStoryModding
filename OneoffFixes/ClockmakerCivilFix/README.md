# Clockmaker Civil Fix

Server-side one-off Vintage Story content mod that removes `civilgloo` from the
GloomeClasses replacement Clockmaker class.

Target asset:

```text
gloomeclasses:config/characterclasses/gloomeclasses.json
```

Patch target:

```text
/10/traits/6
```

In GloomeClasses 1.2.4 this is the `civilgloo` trait in `clockmakergloo`.
