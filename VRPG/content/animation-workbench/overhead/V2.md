# Low-impact revision

Review video: [overhead-v2.mp4](previews/overhead-v2.mp4).

`candidate-v2.patch.json` is a separate authoring candidate, not a runtime skill.
Frames 0–17 are unchanged from V1. Frames 18–21 accelerate into a low strike;
21–24 hold the impact and the remaining frames recover. At 30 fps the final
four-frame cut takes approximately 133 ms, with impact at 700 ms.

The actual sword tip center reaches approximately 0.45 model pixels above Y=0.
This is a foot-level visual target ahead of the character, not a hit on its feet.
Blade roll during frames 18–24 deviates less than 0.11 degrees from the projected
frame-17 blade normal. This does not establish engine blending or damage timing.

The V2 job uses `seraph-without-embedded-sword.json`: the original embedded sword's
faces are hidden in this diagnostic clone, retaining nodes used by animation keys.
Exactly one external sword is attached. The original ActionCombat seraph and item
shape remain untouched. Earlier V1 jobs still include both swords and should not
be used for visual evaluation.

Authoring: `python3 VRPG/tools/animation/overhead_impact.py` emits the patch on stdout.
Validation: `python3 -m unittest discover -s VRPG/tools/animation -p 'test_overhead*.py'`.
Sampling uses `playback-v2.job.json` with the modeler bridge runner.
