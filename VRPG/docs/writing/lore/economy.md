# Economy

Reference for currency, socket/gem, and rune-equivalent naming, so VRPG extends
the base game's economy instead of inventing a parallel one next to it.

## Rusty Gears & Temporal Gears

Rusty gears are the base game's only currency, used exclusively at trader carts.
Temporal gears are simultaneously a rarer currency and a consumable: equip one
in the offhand, use a knife in the main hand, and the player cuts themselves to
insert it, taking about 2 HP of damage in exchange for instantly restoring 30%
temporal stability. The same object is money and a ward against the Rust World
at once. That overlap is the single most useful economic idea in the base game:
currency is not neutral here, it is physically tied to survival.

Traders restock on a delivery timer and gain or lose a small number of gears
at each delivery. Nine trader types exist, each buying and selling a fixed
category of goods (see `history-and-factions.md`). Prices are per-trader and
can differ enough that buying from one and selling to another is a legitimate
way to profit.

## What This Means For VRPG

- VRPG's currency/crafting-sink items should read as *more of the same economy*
  (additional gear-like tender or additional stability-adjacent consumables),
  not a second unrelated currency track.
- Do not invent a new base currency (no "coins," no "shards-as-money"). If VRPG
  needs a crafting-sink resource, name it as a variant or byproduct of gears
  rather than something unrelated.
- Socket/gem and rune-equivalent systems (see the style guide's naming
  patterns) should be grounded in the same clockwork vocabulary gears already
  established (cogs, mechanisms, tuning) rather than generic crystal or rune
  imagery, so they read as part of the same object the player already
  recognizes as both money and a ward.
